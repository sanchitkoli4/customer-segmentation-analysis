# 📊 Customer Segmentation Analysis using K-Means Clustering

## 📌 Project Overview

Customer segmentation is one of the most effective techniques for understanding customer behaviour and developing targeted marketing strategies. This project analyses customer purchasing patterns using SQL, Python, Machine Learning (K-Means Clustering), and Power BI to identify distinct customer groups and provide actionable business recommendations.

The objective is to help businesses improve customer retention, optimise marketing campaigns, and increase revenue through data-driven decision-making.

---

## 🎯 Business Problem

Businesses often apply the same marketing strategy to all customers, leading to inefficient promotional spending and lower customer engagement.

This project aims to answer:

- Which customers are the most valuable?
- Which customer groups require targeted marketing?
- Which segments have the highest purchase potential?
- How can customer segmentation improve business performance?

---

## 🎯 Project Objectives

- Perform customer behaviour analysis.
- Identify purchasing patterns across customer segments.
- Build meaningful customer groups using K-Means Clustering.
- Develop interactive Power BI dashboards.
- Generate business recommendations based on data insights.

# 🤖 Machine Learning Approach

### Algorithm

- K-Means Clustering

### Features Used

- Age
- Purchase Amount (USD)
- Previous Purchases
- Review Rating

### Data Preprocessing

- Missing Value Validation
- Feature Selection
- StandardScaler
- Elbow Method for Optimal Cluster Selection

**K = 5**
